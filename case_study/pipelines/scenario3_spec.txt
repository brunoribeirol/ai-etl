Read the file case_study/data/orders.csv, the PostgreSQL table public.customers, and the REST API at https://api.open-meteo.com/v1/forecast?latitude=-8.05&longitude=-34.88&daily=temperature_2m_max&timezone=America/Recife&forecast_days=7. Join orders and customers on customer_id. Add a column "city_max_temp" by matching each customer city to the weather forecast. Filter active orders only. Save the result to the PostgreSQL table public.enriched_orders.
